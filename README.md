# CS-305-mod8
Client and Requirements
The client for this project was Artemis Financial, a financial services company seeking to improve the security of its software application. The company wanted vulnerabilities identified and mitigated to protect sensitive customer data and ensure secure financial transactions.

Strengths and Importance of Secure Coding
I effectively identified software security vulnerabilities using automated tools and careful analysis of dependency reports. Secure coding is critical because it protects sensitive data, prevents breaches, ensures regulatory compliance, and helps maintain customer trust and company stability.

Challenging and Helpful Aspects
Interpreting vulnerability scan results and determining which issues were most critical was challenging but also highly valuable, as it improved my ability to prioritize and address real security risks.

Security Layers and Future Assessment
I increased security by applying secure coding practices and addressing vulnerable dependencies. In the future, I would continue using tools such as OWASP Dependency-Check, static analysis tools, and penetration testing to assess vulnerabilities and select appropriate mitigation strategies.

Ensuring Functionality and Security
After refactoring the code, I verified functionality and security by retesting the application and rerunning vulnerability scans to ensure no new issues were introduced.

Tools and Practices Used
This project used OWASP Dependency-Check, secure coding standards, and Java security libraries, all of which will be useful in future software development work.

Artifacts for Employers
For future employers, I would present the completed vulnerability assessment and secure software practices documentation to demonstrate my ability to analyze risks, implement security controls, and maintain high-quality, secure code.
